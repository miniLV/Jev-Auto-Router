CODEX TURN ROUTER · COST BOUNDARY

先降 effort，再降 model

切 model 要重建 prefix；切 effort 保留 cache。收益取决于你从哪一格开始。

强 + high

最贵。简单活也按 frontier 价格烧 reasoning。

便宜 + high

省单价，但切过去要重建；高 effort 也不一定便宜。

强 + low

最稳的收益：模型不变，cache 保留，少烧 reasoning。

便宜 + low

最便宜，但质量风险最高；只适合可验证的简单活。

先降 effort
再降 model（break-even 后）
一句话：model 换的是单价，effort 换的是 token 量；前者要重建 cache，后者不用。
