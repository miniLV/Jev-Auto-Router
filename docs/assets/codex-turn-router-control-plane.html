模型 gate

① 价格表 → break-even；没有价格表 → 20k 阈值
② 冷缓存 → 降级放行；热缓存 → 算成本
③ 升级只认 failure / 高复杂度 / 用户指定
④ 超过 N 轮、切换预算或 cooldown → 锁定

Effort gate

① 评分 → low / medium / high / xhigh / max
② 受模型 supported efforts 与 cap 约束
③ request-level effort 保持 baseline
④ 变化用 configuration_update；历史 update 原地重放
