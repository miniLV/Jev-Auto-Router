# Triage Labels

本地 issue 文件的 `Status:` 使用以下五个状态。

| Skill 角色 | 本地状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 说明完整，可交给 agent |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不实施 |

技能提到某个 triage 角色时，在文件中写入对应的本地状态。
